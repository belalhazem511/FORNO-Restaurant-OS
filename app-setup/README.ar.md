# SOLO Restaurant OS لنظام Windows

## التثبيت

شغّل `SOLO-Setup-x64.exe` واتبع خطوات تثبيت Windows. التثبيت خاص بالمستخدم ولا يحتاج إلى صلاحيات مدير أو Bun أو Node.js أو Git أو اتصال بالإنترنت لتشغيل المطعم. عند التشغيل الأول يظهر معالج إعداد محلي؛ أكّد إنشاء قاعدة بيانات جديدة لهذا الجهاز فقط. لا تحدد مجلد بيانات موجوداً كإعداد جديد.

تُحفظ قاعدة البيانات وصور المنتجات خارج مجلد التثبيت ضمن بيانات مستخدم Windows. إذا وُجدت بيانات قديمة باسم `FORNO Restaurant OS` فسيستخدمها SOLO في مكانها، ولن ينقلها أو يحذفها تلقائياً.

## التشغيل المحمول

ضع `SOLO-Portable-x64.exe` و`Run-SOLO.cmd` في المجلد نفسه، ثم شغّل ملف الأوامر أو التطبيق المحمول. تظل بيانات المطعم في مجلد بيانات المستخدم، وليس بجوار ملف التشغيل.

## النسخ الاحتياطي والاستعادة والإصلاح والإزالة

استخدم صفحة التخزين داخل SOLO لإنشاء نسخة احتياطية موثقة أو استعادتها بعد التأكيد. للإصلاح أو الترقية شغّل `Repair-SOLO.cmd` بجوار المثبّت؛ يحتفظ المثبّت ببيانات المستخدم. أزل التطبيق من إعدادات Windows أو عبر `Uninstall-SOLO.cmd`. إزالة التطبيق لا تحذف قاعدة البيانات أو الوسائط أو المستندات أو النسخ الاحتياطية.

## اللغة

اختر العربية أو الإنجليزية في معالج الإعداد الأول. لا يتطلب التثبيت اتصالاً بالإنترنت.
